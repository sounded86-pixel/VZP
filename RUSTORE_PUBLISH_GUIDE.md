# Полное руководство по экспорту из Google AI Studio и публикации в RuStore

Это пошаговая инструкция для выгрузки проекта **«Взаимопомощь»** из среды Google AI Studio Build, превращения его в нативное Android-приложение (`.apk` / `.aab`) и прохождения модерации в официальном российском магазине приложений **RuStore**.

---

## Шаг 1. Экспорт исходного кода из Google AI Studio на ваш компьютер

В среде Google AI Studio код хранится в облаке. Чтобы собрать APK для RuStore, проект необходимо перенести на ваш ПК (Windows, macOS или Linux):

### Вариант А (Самый простой — через кнопку GitHub в AI Studio)
1. В правом верхнем углу интерфейса AI Studio Build нажмите на кнопку **GitHub** или **Export to GitHub**.
2. Авторизуйтесь под своим аккаунтом GitHub и подтвердите создание репозитория (например, `vzaimopomosh-app`).
3. Склонируйте созданный репозиторий на свой компьютер:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/vzaimopomosh-app.git
   cd vzaimopomosh-app
   ```

### Вариант Б (Через скачивание ZIP-архива)
1. Если доступна кнопка **Download ZIP** в AI Studio, скачайте архив на диск и распакуйте его в удобную папку (например, `C:\Projects\vzaimopomosh`).
2. Откройте терминал или командную строку в этой папке.

---

## Шаг 2. Подготовка окружения на компьютере

Для сборки Android-приложения вам понадобятся:
1. **Node.js** (версия 18 или 20 LTS): [nodejs.org](https://nodejs.org/)
2. **JDK (Java Development Kit)** версии 17 или 21: [Adoptium Temurin](https://adoptium.net/)
3. **Android Studio**: [developer.android.com/studio](https://developer.android.com/studio)
   - При установке отметьте галочки **Android SDK**, **Android SDK Platform-Tools** и **Android SDK Build-Tools**.

---

## Шаг 3. Инициализация и сборка веб-приложения

В папке проекта выполните в терминале:

```bash
# 1. Установка всех библиотек
npm install

# 2. Установка Capacitor для нативной сборки Android
npm install @capacitor/core @capacitor/cli @capacitor/android

# 3. Сборка веб-ядра Vite
npm run build
```

После выполнения появится папка `dist/` с готовым скомпилированным приложением.

---

## Шаг 4. Добавление Android-платформы через Capacitor

Конфигурационный файл `capacitor.config.json` уже создан в корне проекта:
```json
{
  "appId": "ru.vzaimopomosh.app",
  "appName": "Взаимопомощь",
  "webDir": "dist"
}
```

Выполните команды в терминале:
```bash
# Инициализация папки с нативным проектом Android
npx cap add android

# Копирование сборки веб-приложения в Android проект
npx cap sync android
```

Теперь в проекте появилась папка `android/` — это полноценный нативный Android Studio проект!

## Шаг 5. Открытие в Android Studio и проверка

Вы можете открыть Android-проект одной командой:
```bash
npx cap open android
```

Или откройте **Android Studio** -> **Open** -> выберите папку `android/`.
Дождитесь завершения индексации и синхронизации Gradle.

## Шаг 6. Создание цифрового ключа подписи (Keystore)

Для публикации в RuStore приложение обязательно должно быть подписано вашим релизным ключом.

Сгенерируйте ключ через терминал (выполняется 1 раз):
```bash
keytool -genkey -v -keystore release-key.jks -alias vzaimopomosh -keyalg RSA -keysize 2048 -validity 10000
```
> Задайте пароль и запомните его, а также сохраните файл `release-key.jks` в надёжном месте.

---

## Шаг 7. Сборка релизного APK или AAB

### Способ 1: Через графический интерфейс Android Studio (Рекомендуется)
1. В верхнем меню Android Studio выберите **Build** -> **Generate Signed Bundle / APK...**.
2. Выберите **APK** или **Android App Bundle (AAB)** (RuStore принимает оба формата).
3. Укажите сгенерированный ранее файл `release-key.jks`, пароли и алиас `vzaimopomosh`.
4. Выберите тип сборки: **release**.
5. Отметьте сигнатуры **V1 (Jar Signature)** и **V2 (Full APK Signature)**.
6. Нажмите **Finish**. 
Файл будет создан в `android/app/release/app-release.apk`.

### Способ 2: Через командную строку (Gradle)
```bash
cd android
./gradlew assembleRelease
# (на Windows: gradlew.bat assembleRelease)
```
И затем подписать полученный `app-release-unsigned.apk` через `apksigner`.

## Шаг 8. Публикация в RuStore (Консоль разработчика)

1. Перейдите на официальный портал разработчиков: **[https://console.rustore.ru/](https://console.rustore.ru/)**
2. Авторизуйтесь (через VK ID или Госуслуги) и зарегистрируйтесь как физическое лицо, самозанятый, ИП или организация.
3. Нажмите кнопку **«Добавить приложение»**.
4. Заполните форму:
   - **Тип приложения**: Мобильное приложение
   - **Название**: `Взаимопомощь`
   - **Пакет (Package Name)**: `ru.vzaimopomosh.app`
5. **Загрузка сборки**:
   - Загрузите ваш сгенерированный `.apk` или `.aab` файл.
6. **Оформление карточки приложения**:

- **Название приложения:** 
  > Взаимопомощь: Добрососедство в деревне

- **Краткое описание (до 80 символов):**

- **Полное описание:**

  > 
  > Главная цель проекта — возродить традиции добрососедства и взаимной выручки:
  > 
  > 🤝 «ПОМОЩЬ РЯДОМ» — публикуйте просьбы о помощи (наколоть дрова, привезти продукты или лекарства из райцентра, вспахать огород, починить забор) или предлагайте свою бескорыстную помощь соседям.
  > 
  > 💬 ПРЯМАЯ СВЯЗЬ — общайтесь с откликнувшимися соседями в безопасном чате без спама и посредников.
  > 
  > 🚗 ПОПУТНЫЕ ПОЕЗДКИ — находите попутчиков между деревнями и райцентром.
  >

  > 🌿 ЭКОЛОГИЯ — адреса сельских пунктов приёма использованных батареек.

  > Социальные сети / Инструменты и утилиты

- **Возрастной ценз:** 
  > 0+ или 12+

- **Графические материалы:**
  - Иконка приложения: 512×512 px в формате PNG без прозрачного фона.
  - Скриншоты: минимум 2 скриншота экрана (1080×1920 px). Их можно сделать прямо в браузере или на телефоне.

7. Нажмите **«Отправить на модерацию»**.
   - Проверка приложения модераторами RuStore обычно занимает от 3 часов до 1-2 рабочих дней.
   - После одобрения приложение сразу появится в каталоге RuStore и будет доступно для скачивания миллионам пользователей по всей России.
